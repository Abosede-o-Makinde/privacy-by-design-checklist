Regenerate with:

```bash
python main.py --mode report --input sample_data/meeting_notetaker.json --output sample_outputs/
```

- `MEETING-NOTES-001_checklist.md` — prioritised go-live checklist (PARTIAL, 14 open items)
- `MEETING-NOTES-001_assessment.pdf` — full assessment report
